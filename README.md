## Descrição do Projeto

Este projeto apresenta uma solução em Power BI para monitoramento e controle financeiro empresarial com base em dados históricos dos anos de **2019, 2020 e 2022**. O objetivo é oferecer suporte à tomada de decisão estratégica através da análise temporal de fluxo de caixa, confronto entre **Receitas vs. Despesas** e detalhamento dos componentes de custo e receita.
